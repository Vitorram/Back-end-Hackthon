# SIGTEC API

API REST para gerenciamento de equipamentos públicos, desenvolvida durante o **Hackathon IFSP 2026**.

## Sobre o projeto

O sistema foi criado para centralizar o cadastro e o gerenciamento de equipamentos, oferecendo uma API para operações administrativas e controle das informações.

## Tecnologias

- Python
- FastAPI
- MySQL
- JWT
- Uvicorn

## Principais recursos

- Cadastro e consulta de equipamentos
- Operações CRUD
- Autenticação e autorização
- Integração com banco de dados
- API documentada

## Arquitetura


```text
Cliente
   ↓
FastAPI
   ↓
Regras de negócio
   ↓
MySQL
```

## Documentação

Com a API em execução, a documentação interativa pode ser acessada pelo Swagger disponibilizado pelo FastAPI.

## Objetivo

Aplicar desenvolvimento de APIs REST, autenticação, persistência de dados e organização de backend em um projeto com contexto real de uso.
